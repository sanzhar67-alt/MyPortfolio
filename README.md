# MyPortfolio

Личное портфолио Раяны Бектемировой — адаптивный одностраничный сайт, созданный на HTML и CSS.

## Что внутри

- Обо мне
- Навыки
- Учебные проекты
- Контактная секция

## Технологии

- HTML5
- CSS3

## Запуск

Откройте `index.html` в браузере.

## GitHub Pages

Чтобы опубликовать сайт, откройте **Settings → Pages**, выберите ветку `main` и папку `/(root)`, затем нажмите **Save**. После публикации адрес сайта будет:

https://sanzhar67-alt.github.io/MyPortfolio/
